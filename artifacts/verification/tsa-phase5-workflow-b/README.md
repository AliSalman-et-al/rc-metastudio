## Replay

Use Windows x64 and Poppler's `pdftotext` on PATH. Set `RCMS_R_HOME` to the
packaged R 4.6.2 runtime and `RCMS_R_LIBS` to a test-owned copy of the
manifest-pinned library. The replay uses the bundled BCG and Pignon projects
and the MD, RR/MH, SMD and stress fixtures generated by
`tests/e2e/trial_sequential_workflows.py`. The host was set to 125% system
scaling. Set `-SystemScale` if replaying on a different host.

```powershell
uv sync --locked
uv run python scripts/build_qt6.py generate --build-root build/qt6-verification
$replay = "artifacts/verification/tsa-phase5-workflow-b/replay.ps1"
& $replay typing -Run delivery
& $replay r -Run delivery
& $replay python -Run delivery
& $replay native100 -Run delivery
& $replay native150 -Run delivery
uv run python -X utf8 artifacts/verification/tsa-phase5-workflow-b/audit.py delivery
```

The replay writes each command, transcript and exit status under `delivery/`.
The typing receipt includes the full `win32` Ty command, form search paths and
the result. Native lanes run the verify-rcms doctor and six TSA workflows with
`--native`. The full manifests, scenario logs, inputs, screenshots and exports
are retained locally under `delivery/native100/` and `delivery/native150/`.
The committed captures above are unmodified copies from those runs.

## Preview timings

RC MetaStudio's embedded R session runs on the GUI thread. The existing
asynchronous path launches a fresh R process per conclusion preview.
A persistent background R session would require a separate worker protocol
and lifecycle, so this change keeps the existing process model.

RIS medians use seven warm samples and exclude the 120 ms debounce.
Conclusion times are individual observations from changing the input to
receiving the text, including the 600 ms debounce and R process startup.
Other test processes were active during these measurements.

| Fixture | Scale | RIS median | Conclusion elapsed |
| --- | ---: | ---: | ---: |
| BCG REML | 100% | 57.18 ms | 5.81 s |
| Pignon HR | 100% | 72.85 ms | 7.36 s |
| BCG REML | 150% | 39.34 ms | 5.13 s |
| Pignon HR | 150% | 52.17 ms | 5.79 s |
