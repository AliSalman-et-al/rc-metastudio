# F2 verification plan

Export each produced plot kind through Results at 85 mm and 180 mm with the proportional height shown by the dialog. Include PDF, SVG, SVGZ where accepted, PNG and TIFF. Read PDF media boxes, SVG viewport dimensions and raster resolution metadata independently. Compare both dimensions with the requested size to within 0.5 mm and retain a CSV and white-paper renders.

At 85 mm assess minimum effective text size (6 pt), margins and content clipping. With the complete content selected, capture any legibility message before choosing a destination. Use phase 1 forest and TSA measurements to demonstrate the initial discrepancy.
