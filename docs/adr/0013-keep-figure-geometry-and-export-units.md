# 0013. Keep figure geometry and export units

## Context

R fits and renderers use analysis coordinates. Qt, Word, and print devices
consume figure geometry in display and physical coordinates. Plot edits or
device changes can otherwise alter inferential quantities, clip output, or
freeze computed defaults as user overrides.

## Decision

- Transform forest coordinates only. Keep fitted effects and variances on the
  analysis scale. The Freeman–Tukey inverse uses each study's N for study
  coordinates and the harmonic mean for pooled coordinates, including **both**
  prediction endpoints. A length-two endpoint vector still represents one
  pooled interval.
- Save explicit edits separately from resolved forest defaults. Regeneration
  can recompute defaults from the saved plot and avoid a second transform.
  Continue to read cumulative labels saved with their step counts. If positive
  standard errors collapse a range through floating-point rounding, expand
  only the collapsed range so small finite effects retain their scale.
- Compute regression ticks from the drawn fit range, which includes the
  fitted confidence and prediction bands. Study estimates alone can leave
  the bands outside the tick coverage.
- Render SROC appearance changes over the captured geometry. Keep the
  observed and summary accent separate from curve colors. Show the curve
  legend by default so static exports distinguish prediction and confidence
  regions. The marker-size legend has its own state.
- Adapt svglite output for Qt's SVG renderer. Use the viewBox for percentage
  canvas sizes. Use symbol viewports for clipping because Qt ignores the
  clip paths generated by R. Move the viewport to the origin for clipping,
  then translate back to the R coordinates. This keeps marks vector at
  print resolution. Use bare font families for Qt's glyph fallback and
  bound explicitly drawn forest summary vertices.
- Read device SVG as UTF-8 and remove illegal XML control bytes and references
  before XML parsing. A native Windows code page or unknown-encoding R
  string can otherwise damage labels or defeat character-based filtering.
  Carry physical viewport dimensions to the PDF backend in points and
  keep publication rasters packed to bound memory. Preview devices can
  cap DPI while explicit publication exports keep their requested DPI.
- Lay out regression, funnel, SROC and trial sequential exports at the
  requested physical dimensions. Check the text advances on the same
  svglite device before enabling Save. The editor keeps its natural-size
  preview, and forest exports retain their measured minimum width.
- Print real paginated text tables on white pages under either app palette.
  Give figures and captions their own pages. Keep short captions and
  tables together, allow long tables to paginate with repeated headers,
  and lay the document out again after inserting breaks. Fit unbreakable
  table cells to page width before pagination. For Word, assign the same
  border to both cells sharing the edge below a header.

The dataset-type diagram icons express the formulas in their outline paths.
The source glyphs include generic effect `(θ, SE)`, hazard ratio `h₁(t)/h₂(t)`,
incidence rate ratio `(x₁/T₁)/(x₂/T₂)`, single-arm mean `μ`, proportion `x/N`,
regression coefficient `β`, and standardized difference `g`. Two-arm icons
show the pair of means or proportions. The time/event icon shows HR and IRR.

## Presentation defaults

Translate untouched Qt form placeholders into unset values at the presentation
boundary. Keep the renderer independent of widget text. Use the same bitmap
size guard in Python export setup and RCMetaR device allocation. Reserve the
normal forest body-text floor from study text rather than small fitted
annotations.
