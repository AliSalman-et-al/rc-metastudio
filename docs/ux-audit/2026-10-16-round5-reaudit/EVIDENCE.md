[EVIDENCE.json](EVIDENCE.json) binds the published documents, audit scripts and curated images (excluding its own hash). Raw logs and helper workflow trees remain ignored. Original helper step records can name a temporary `build/verification/...` path that has been cleaned; the retained file is in that run's `artifacts/verification/rcms/.../workflow/` tree and is bound by its manifest. Resolve incidental screenshot paths through CURATION. These records preserve failed/rejected attempts without citing them as successful proof.

A successful process is not an overall UX verdict. Numerical/geometry contracts can pass while a legend, wrapped label or CI cap is poor; the targeted calculator probe deliberately completes while demonstrating data loss. Coverage limits and source-supported versus native comparisons are explicit in REPORT.
