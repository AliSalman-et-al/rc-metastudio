# Review-round behavior to prove before implementation

Use the production Qt/R driver and native Windows platform. Retain commands,
inputs, runtime, assertions, screenshots and failed attempts.

- A wide amino two-arm forest opens in figure view with its complete left/right
  columns. After manual 125% zoom and horizontal scrolling, Fit width restores
  complete bounds. Navigation resets horizontal scroll; resize preserves fit.
- Every workflow uses its own first-column default, including standard Study
  after subgroup. Backend parameters and rendered labels agree.
- Headers have at most three explicit lines; no inferred study counts. Model,
  inference, confidence and interpretation remain available in report export.
- Native report Ctrl+C copies the selection and Ctrl+Shift+C copies the report.
- Invalid real-R method parameters keep setup open, show/focus one readable
  inline error, then a corrected request succeeds.
- Boolean enum controls derive from TRUE/FALSE metadata and retain backend
  values; method metadata owns correction labels.
- Single-arm mean, coefficient and entered-effect report labels come from the
  request; diagnostic coefficient headings come from structured plot metadata.
- Capture standard, cumulative, omission, subgroup, regression, single-arm,
  continuous and diagnostic native results; inspect every retained screenshot
  for missing glyphs. Run the complete Python/desktop and current-source R lanes.
