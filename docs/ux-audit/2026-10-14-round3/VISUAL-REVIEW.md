# Native visual review

All 26 unmodified PNGs indexed in SCREENSHOTS.json were opened and inspected after
curation from the twelve `native-dx-*` runs on 2026-10-14. The native runtime was
Linux xcb, Qt 6.11.1 / PyQt 6.11.0 and pinned R 4.6.1.

The retained views show aligned cumulative/omission study labels and intervals;
HR/IRR omission-only figures with no invented overall row; the named IRR
non-estimable row; fixed-effect footers retaining Q/df/P/I² and omitting τ²;
configuration-first subgroup tables with fitted k, heterogeneity and existing PI;
component-specific diagnostic estimator/inference; an excluded null reference in
the edited 0.5–2 MD range; zero bounds without floating residue; readable ordinary
and tiny-effect weight/estimate columns; five scientific ticks and six visible
tiny-effect intervals; and bubble ticks over the plot's vertical range.

The HR plot requires scrolling. Its top/bottom screenshots show the actual
viewport, while every row's numerical/name correspondence is proved separately
against the complete SVG and report in OBSERVATIONS.json. Report text artifacts
contain the actual identity-prefixed, tab-separated copy/export payloads. Native
file picker behavior, fractional DPI, accessibility and installed release packages
are not established by these controlled drives.
