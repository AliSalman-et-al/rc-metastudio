# User-facing copy

Use the terms in [CONTEXT.md](../CONTEXT.md). In the app and exports, call a data tab an **outcome** and an analysis quantity an **effect measure**. Use **Data tables** for the Results page and **Report tables** for the link within Text report.

- Use sentence case for actions, headings, and labels. Preserve proper names and statistical symbols. Use **Small-study effects…** and **Trial sequential analysis…** in the Analysis menu.
- Use US English, straight quotes and apostrophes, and a single ellipsis character for actions that ask for more input. Join paired author names with an en dash, as in Mantel–Haenszel and DerSimonian–Laird.
- Write **P value**, **P < 0.001**, and **P = 0.014**. Use **Not estimable** when an effect cannot be estimated.
- Say **file** or **spreadsheet** in shared import instructions. Name a format when it determines what the user can open or export.
- Describe what the control does or how to recover from an error. Keep statistical methods, numerical results, package provenance, and quoted publication titles precise.
